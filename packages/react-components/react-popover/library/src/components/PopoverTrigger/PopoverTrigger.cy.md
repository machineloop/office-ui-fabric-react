## Deliberate boundaries

This component is a child-cloning trigger, not a styled root or slots component. There is no supported trigger-owned size, appearance, label slot, controlled state or forwardRef API; child native attributes/ref and parent state are the relevant contracts. Arrow rendering, placement accuracy/autosizing, surface motion timelines, custom positioning targets and no-trigger operation belong to parent/surface/positioning suites; the relevant story modules were read, not certified here. No pixel, screen-reader, cross-browser or universal exhaustive claim is made. The historical Spec mentions focus-to-open and Shift+F10 context activation; neither is implemented by the current trigger hook as a special keyboard handler. Further rounds will probe actual supported a11y/child composition and unit-derived contracts rather than treating historical proposals as current APIs.

### Tightly coupled production correction

Round 2 review identified missing Escape injection in context-menu mode. The initial 34-test run reproduced that an open context popover ignored trigger-focused native Escape. Since this contradicts the documented Escape contract and is wholly inside this directory, `usePopoverTrigger.ts` now merges the shared keydown handler into `contextMenuProps`. The click toggle remains excluded for context mode. Two component-local Jest regressions assert child-first dismissal and consumer cancellation. A Beachball file is intentionally omitted because the campaign explicitly forbids writes outside this component directory.

Round 3 review identified a second tightly coupled problem: handled trigger Escape prevented the default but did not actually stop propagation despite the source comment. In a nested popover, Escape on an inner trigger could dismiss the outer surface as well. The handler now stops propagation when it closes. Two native browser cases keep focus on the inner trigger (click and context mode), assert inner-only dismissal and zero outer callbacks; two Jest cases assert the ancestor handler is not called.

Execution and independent reviews are recorded in the artifact checkpoint, not inferred from this inventory.
