## Commands

From the master checkout, using existing dependencies:

```powershell
$repo = (Get-Location).Path
$node = 'C:\Program Files\scout\resources\node\node.exe'
$component = "$repo\packages\react-components\react-table\library\src\components\DataGridRow"
& $node "$repo\node_modules\cypress\bin\cypress" run --component --browser electron --headless --project "$repo\packages\react-components\react-table\library" --config-file src\components\DataGridRow\cypress.config.cjs
& $node "$repo\node_modules\typescript\bin\tsc" -p "$component\tsconfig.cy.json"
& $node "$repo\node_modules\prettier\bin-prettier.js" --check "$component\*.cy*" "$component\cypress.config.cjs" "$component\tsconfig.cy.json"
```

Local CommonJS config deliberately bypasses the canonical ESM config incompatibility; local legacy JSX declarations accommodate React 19 types. Artifacts stay in this component; logs are in the requested session artifacts directory. Existing shared webpack include-pattern warnings remain visible.

## Limits

Electron functional coverage only, not universal accessibility, assistive technology, high-contrast OS, cross-browser or visual certification. Column drag/keyboard-resize and the external virtualized extension belong to separate components/packages; the row suite checks their local column-context/geometry and removal contracts, not those implementations. Keyboard uses real native events, including the browser's synthesized button click after Space; this is asserted separately from excluded interactive key selection. No retries, sleeps, skipped tests, network fixtures or error suppression.
